# 项目变量（跨会话静态事实源）

> 本文件只记录不随代码变化的静态事实，便于协作与交接；与仓库实际情况冲突时以代码为准并更新此处。

| 变量 | 值 |
|---|---|
| 项目名 / 类型 | shop_demo（随心商城）/ 电商商城演示项目（前台 + 后台管理系统） |
| 技术栈 / 后端目录 | FastAPI（Python >= 3.10，uv 管理依赖）+ aiomysql 全异步 / `backend/` |
| 数据库 | MySQL 5.7+；连接参数全部来自 `backend/.env`（由 `.env.example` 复制后自行填写），仓库内不含任何个人或生产环境凭据（文中口令均为可替换的本地演示值）；`JWT_SECRET` 为必填项，缺失即启动失败 |
| 认证 | JWT + bcrypt；后台与会员端令牌，会员端未配 `MEMBER_JWT_SECRET` 时回退 `JWT_SECRET` |
| RBAC | 需（JWT + 角色 / 权限码 / 数据权限 / 操作审计） |
| 运行端口架构 | **8001 = 后端接口服务 + 后台管理系统 `manager/`**（FastAPI 同源托管，根路径自动跳 `/manager/login.html`，`/api/v1/*`、`/api/docs`、`/api/v1/health` 同址）；**8000 = 商城前台 `front/`**（纯静态独立托管，站点根为 `front/` 目录，`http://127.0.0.1:8000/` 即首页） |
| 前台接入状态 | 18 页全部接入 `/api/v1/shop/*` 真实接口（跨域请求 8001）；后端 `CORS_ORIGINS` 需放行前台来源 |
| 后台页面 | `manager/` 共 28 个页面（含登录页与仪表盘，其中 **26 个功能页**），全部接入真实接口 |
| seed 规范 | `backend/` 下 `python -m seed.runner <base\|demo\|clean-base\|clean-demo>`；base=建表+基础数据（保留），demo=演示数据（可整删），全部幂等；不带参数时默认执行 `base` |
| 演示数据规模 | 商品 20 / SKU 24 / 商品图记录 42（对应 36 个 SVG 文件）/ 订单 18（覆盖待付款·待发货·已发货·已完成·已取消·售后中 6 态）/ 会员 6（含 1 禁用）/ 评价 16 / 地址 8 / 优惠券 5 / 售后 6 / 购物车 5 / 文章 5 / 广告 5 |
| 演示图片 | 图片源 = 项目内 `front/images/` 36 张自绘 SVG 占位图，执行 `seed demo` 时自动同步到 `uploads/seed/`，数据内 url 为 `http://127.0.0.1:8001/uploads/seed/*.svg`（可用 `UPLOAD_PUBLIC_BASE` / `PORT` 覆盖） |
| 品牌 / 主色 | 品牌 = 随心商城，logo 见 `front/images/logo.png`、`manager/images/logo.png`；全站主色青绿：front `--primary:#1E9E96` / `--primary-hover:#35B5AC` / `--primary-active:#178B84` / `--primary-deep:#0F6E69` / `--primary-light:#EFF9F8`，`--warning:#F59E0B`；manager `common.css`、`login.css` 同步青绿 |
| 接口参数命名口径 | 后端 query 参数一律 **snake_case**（例：`/regions?parent_code=`、`/goods?sort_field=&page_size=&is_recommend=`）；请求体 body 为 **camelCase**（例：`{goodsId, skuId, previewToken, pointsUsed}`）。前端拼 query 时必须用 snake_case |
| 规格文档 | 后台：`specs/商城后台管理系统V2.spec.md`；前台：`specs/商城前台V1.2.spec.md`；前台设计说明：`docs/商城前台逻辑设计说明.md`；功能说明：`后台管理系统功能.md` |
| 依赖安装 | `cd backend && uv sync`（不使用 uv 时：`python -m venv .venv` + `pip install -r requirements.txt`；**开发/测试依赖在 `requirements-dev.txt`**） |
| 常用命令 | 后端：`cd backend && uv run python run.py`（8001）；前台：`cd front && python -m http.server 8000`；数据：`uv run python -m seed.runner base` / `demo`；测试：`cd backend && uv run pytest -q tests`（当前基线 84 passed） |
| 测试前置 | 需真实 MySQL 可达且已执行 `seed base` **与 `seed demo`**（部分用例断言演示数据规模、依赖固定 coupon id，只跑 base 会红）；测试非离线模式 |
| Git | 仓库不记录任何远端地址、账号名或令牌；`backend/.env` 已在 `.gitignore` 中排除，禁止入库 |
